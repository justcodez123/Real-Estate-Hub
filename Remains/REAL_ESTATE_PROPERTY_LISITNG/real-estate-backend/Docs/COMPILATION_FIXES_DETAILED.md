## 🎓 What Lombok Does

### @Data Annotation
Automatically generates:
- ✅ Getter methods for all fields
- ✅ Setter methods for all fields (except final fields)
- ✅ equals() and hashCode() methods
- ✅ toString() method
- ✅ Constructor with all fields

### @Builder Annotation
Generates:
- ✅ Builder inner class
- ✅ builder() static method
- ✅ Fluent setters on builder (e.g., `User.builder().firstName("John").build()`)

### @NoArgsConstructor
- ✅ Generates no-argument constructor (default constructor)

### @AllArgsConstructor
- ✅ Generates constructor with all fields as parameters
