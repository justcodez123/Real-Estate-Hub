# 🏡 Real Estate Property Listing Platform – Frontend

Frontend application for the **Real Estate Property Listing Platform**, built using **React.js**.  
This UI consumes REST APIs from the **Spring Boot backend** and provides an interactive, responsive experience for browsing and managing real estate properties.

---

## 🚀 Project Overview

This frontend enables users to:
- Browse property listings
- Filter and sort properties dynamically
- View property details with image galleries
- Interact with a modern, responsive UI

The application is designed to work seamlessly with the Spring Boot + MySQL backend.

---

## ✨ Key Features

- 🏠 Property listing and detailed views  
- 🔍 Advanced filtering and sorting  
  - Location  
  - Price range  
  - Property type  
  - Listing type (Rent / Sale)  
- 🖼 Image gallery for properties  
- ⚡ Fast and responsive UI  
- 🌐 REST API integration with backend  
- 📱 Mobile-friendly design
